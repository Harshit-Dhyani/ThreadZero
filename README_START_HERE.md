# Start here

ThreadZero is the internal codename for an independent NCRP financial-fraud concept. The public prototype is labelled **National Cyber Crime Reporting Portal — Independent concept redesign** and uses synthetic data only.

## Current decision gate

Open [the comparison board](prototype/comparison/index.html) and inspect:

1. Parallel Ledger
2. Guided Verification
3. Continuous Thread

These are Evidence + Incident golden screens, not complete applications. Choose one only after reviewing its 1440×900 and 390×844 renders. The complete Home plus nine-step journey is intentionally blocked until that approval.
