# ThreadZero V7.3 — UI Simplification

Date: 2026-08-30
Version: V7.3
Project Mode: Product

## Goal

Reduce visible clutter on Home, Check, Learn, and Help while preserving the underlying citizen tasks, official-action boundaries, static-export architecture, and existing Report/Track behavior.

## Change

### Home
- Remove the `Independent concept` eyebrow from the Home hero.
- Keep the primary hero, incident timeline mechanism, and four-step `How it works` strip.
- Remove the former Home-only Citizen services, Evidence-connected explainer, and Learning Corner sections.

### Check
- Remove the `Demo Check workspace` eyebrow.
- Remove the visible four-item `Demo only / No upload / No live lookup / Official handoff` status row.
- Replace that treatment with one calm sentence explaining that ThreadZero uses local examples and does not contact official systems.
- Preserve all seven Check modes and deterministic fixture behavior.
- Rebuild `Report or take action` as one consistent rounded action group with equal row rhythm, `px-5 py-4` spacing, 44px icon targets, and a fixed safe arrow column.
- Keep truthful result copy stating that illustrative results are not government or live-database lookups.

### Learn
- Route the `learning-corner` landing page through a dedicated V7.3 surface.
- Increase hero illustration presence to a dedicated 430–480px media column with a `max-h-72` image stage.
- Organize the page as situation-first choices, latest practical alerts, then a compact resource directory.
- Preserve the broader Learn route family.

### Help
- Route the `contact` landing page through a dedicated V7.3 surface.
- Increase hero illustration presence to a dedicated 430–480px media column with a `max-h-72` image stage.
- Present three clear help paths, then a prominent Immediate help / 1930 band, then official help destinations.
- Preserve FAQ, feedback, grievance, and other Help routes.

### Footer
- Increase the guidance illustration from roughly 96–112px to roughly 144–160px while preserving navigation and creator/social behavior.

## Reason

User review of the V7.2 production UI found that prototype labels, status chips, dense Home sections, weak action-row spacing, and undersized illustration treatment made the product feel less polished. The V7.3 change removes those presentation problems without deleting Check, Learn, Help, Report, or Track capabilities.
