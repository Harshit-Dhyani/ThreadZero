# ThreadZero V7.4 Unified Hybrid UX Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restore the useful Home sections and unify Report, Track, Learn, Help, and footer presentation around the approved Hybrid civic/product UX without changing core behavior.

**Architecture:** Keep each existing workspace owner intact and make presentation-only changes. Add one reusable `WorkspaceRail` for the Learn/Help route families, restore Home from the known-good pre-V7.3 component, add a page-level Report masthead while demoting step headings to H2, compress Track's progress block, replace the V7.3 Learn/Help landing owner with a V7.4 owner, and turn the footer guidance illustration into a background-style composition.

**Tech Stack:** Next.js 16.3.3, React 19, TypeScript, Tailwind utility classes, Bun 1.3.14, static export, node:test regression suite.

**Spec:** `docs/superpowers/specs/2026-08-30-v7.4-unified-hybrid-ux.md`

## Global Constraints

- Preserve all six public workspaces and existing public URLs.
- Preserve all seven Check modes and deterministic Check fixtures.
- Preserve the five Report stages and all Report domain/state/storage behavior.
- Preserve both Track preparation progress and deterministic reference tracking.
- Preserve Learn routes: Overview, Safety, Awareness, Advisories, Daily digest, Training, Media, Accessibility.
- Preserve Help routes: Help options, FAQ, Portal feedback, Complaint / escalation help.
- No backend, auth, database, upload, OCR, RAG, model calls, analytics, or external writes.
- Keep manual `1930` and `cybercrime.gov.in` truth boundaries.
- Maintain one visible H1 per page and 44px minimum interactive targets.
- Check remains the reference workspace and is not structurally redesigned.

- [ ] **Step 1: Implement `WorkspaceRail`**

```tsx
"use client";

import Link from "next/link";
import { useRouter } from "next/navigation";
import { navigationContextFor, navigationLabel } from "@/lib/navigation";
import { localized } from "@/lib/i18n";
import { usePortal } from "./portal-provider";

const pathFor = (route: string) => route === "home" ? "/" : `/${route}`;

export function WorkspaceRail({ routeId }: { routeId: string }) {
  const { language } = usePortal();
  const router = useRouter();
  const context = navigationContextFor(routeId);
  if (!context) return null;
  const label = localized(context.label, language);
  return <aside className="min-w-0">
    <label className="grid gap-2 text-sm font-semibold lg:hidden">
      <span>{language === "hi" ? `${label} अनुभाग चुनें` : `Choose ${label} section`}</span>
      <select value={routeId} onChange={(event) => router.push(pathFor(event.target.value))} className="min-h-11 rounded-control border border-line bg-white px-3 font-normal">
        {context.items.map((item) => <option key={item.route} value={item.route}>{navigationLabel(item, language)}</option>)}
      </select>
    </label>
    <nav aria-label={language === "hi" ? `${label} अनुभाग` : `${label} sections`} className="sticky top-5 hidden rounded-panel border border-line bg-white p-3 lg:block">
      <p className="px-3 pb-2 text-xs font-semibold uppercase tracking-[0.12em] text-civic-700">{label}</p>
      {context.items.map((item) => <Link key={item.route} href={pathFor(item.route)} aria-current={item.route === routeId ? "page" : undefined} className={`flex min-h-12 items-center rounded-control px-3 text-sm font-semibold ${item.route === routeId ? "bg-civic-50 text-civic-700" : "text-ink hover:bg-civic-50 hover:text-civic-700"}`}>{navigationLabel(item, language)}</Link>)}
    </nav>
  </aside>;
}
```
