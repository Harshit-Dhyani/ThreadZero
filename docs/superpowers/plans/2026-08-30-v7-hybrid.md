# ThreadZero V7 Hybrid Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Preserve the restored first-redesign product breadth while making Report genuinely adaptive and Track truthful without deleting useful Check/Learn/Help/Home capabilities.

**Architecture:** Keep the existing shell, Home, Check, Learn, Help, Guide, and Search owners. Move report-family behavior into `src/domains/report/index.ts` as the single state/presentation boundary, then wire `flow-route.tsx` to it. Extend `track.tsx` with a local preparation-progress section while preserving its existing reference/demo tracker.

**Tech Stack:** Next.js 16, React 19, TypeScript, Tailwind, Bun 1.3.14, Node test runner, static export.

**Spec:** `docs/superpowers/specs/2026-08-30-v7-hybrid-design.md`

## Global Constraints

- Preserve static Next.js export and Bun 1.3.14.
- Do not add backend, auth, database, uploads, OCR, RAG, model calls, analytics, or external writes.
- Preserve current Home, all seven Check modes, rich Learn routes, Help routes, Guide, and Search/Ask.
- Preserve public URLs and demo/safety boundaries.
- Keep 1930 manual and cybercrime.gov.in guidance visible where appropriate.
- No feature deletion solely for visual simplicity.
