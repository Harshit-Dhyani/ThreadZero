## Original production image recipes derived from the audit

1. Evidence table overhead: neutral phone, transaction record, notes, and envelope arranged by time; no logos or personal data.
2. Device in context: hands using a neutral report-preparation interface in a warm everyday environment; screen text remains abstract because HTML owns copy.
3. Wide documentary preparation scene: a calm person organizing records without showing distress, authority, or a victim performance.
4. Layered evidence papers: depth and annotation for explanatory sections, with no testimonials, proof claims, or third-party text.

These recipes replace the invalid pre-audit raster drafts.
